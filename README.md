# Carter PC Parkour

A minimalist 3D parkour game built with three.js. Jump across floating blocks, hit the checkpoints and reach the gold tower.

**Play:** https://immortalbobik.github.io/carter-pc-parkour/

## Controls
- **WASD** move, **Space** jump, **Shift** sprint
- **Mouse** look (click to lock the mouse)
- **F5 / V** switch view (third person, first person, front)
- **R** back to checkpoint, **Esc** pause

## Run locally
```
node server.js
```
Then open http://localhost:5173. No install needed.
